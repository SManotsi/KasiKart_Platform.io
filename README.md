# KasiKart Prototype

KasiKart is an offline, interactive front-end prototype for a hyper-local township delivery platform connecting households, spaza shops and local delivery runners.

## Run it

1. Extract the ZIP file.
2. Open the `KasiKart` folder.
3. Double-click `index.html`.

No installation, internet connection, server or database is required.

## Demo experiences

- **Customer:** browse four different nearby shop types, compare delivery details, see each shop's stock quantities and prices, order from one shop through checkout or WhatsApp, track a demo delivery and message the assigned shop or runner.
- **Spaza owner:** review sales, accept orders, see a seven-day chart and update in-stock/out-of-stock items.
- **Delivery runner:** review available delivery jobs, earnings and ratings, then accept a route.
- **Registration:** create a browser-saved demo account using customer, shop-owner or delivery-runner fields.

Use the **View as** selector at the top of the page to switch between the three roles.

## Important prototype note

The checkout, payments, map movement, identity verification and live inventory are simulated. WhatsApp opens a pre-filled order using a placeholder demo number; replace it with the official KasiKart WhatsApp Business number before launch. A production release would require a secure backend, database, authentication, payment provider, WhatsApp Business integration, geocoding, POPIA controls and shop/runner onboarding.
